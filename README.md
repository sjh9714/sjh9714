## 소개

- 가톨릭대학교 컴퓨터정보공학부
- 가톨릭대학교 멋쟁이사자처럼 12기 백엔드
- 동시성, 성능, 관측성 문제를 수치로 확인하고 개선하는 백엔드 개발에 관심이 있습니다.
- 문제를 작게 나누고, 실험 결과를 문서와 코드로 남기는 방식을 좋아합니다.
