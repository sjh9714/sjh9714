## 🌍 Open Source

오픈소스 프로젝트에서 **실제 이슈를 재현하고, 회귀 테스트와 작은 diff로 문제를 해결하는 기여**를 이어가고 있습니다.

제가 중요하게 보는 기여 방식은 다음과 같습니다.

- **Reproducible issue first**: 먼저 문제를 로컬에서 재현합니다.
- **Regression test**: 가능하면 수정 전 실패하고 수정 후 통과하는 테스트를 추가합니다.
- **Small diff**: 메인테이너가 빠르게 리뷰할 수 있도록 변경 범위를 좁게 유지합니다.
- **Review-friendly PR**: 변경 이유, 테스트 명령어, 관련 이슈를 PR 본문에 명확히 남깁니다.
