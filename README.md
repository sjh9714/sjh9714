### [Krea2 Wildcards](https://github.com/sjh9714/krea2-wildcards)

> 새 이미지 생성 모델의 결과를 설치 없이 비교하고 프롬프트를 바로 재사용할 수 있는 웹 갤러리

- **내 역할** 문제 탐색부터 프롬프트·결과 데이터 구축, 갤러리 구현, 커뮤니티 공개 후 탐색 흐름 개선까지 단독으로 진행했습니다.
- **확인 근거** 500+ 프롬프트·생성 결과, 실제 항목이 있는 63개 범주, GitHub 18★·5 forks <sub>2026.08.24 기준</sub> · [Live Gallery](https://sjh9714.github.io/krea2-wildcards/)

### [FinMate](https://github.com/gaga-studio/finmate-app)

> 금융 관리를 시작하거나 지속하기 어려운 20대의 첫 행동을 돕는 금융 온보딩 서비스

- **팀의 판단 근거** 20대 97명의 문제 탐색 설문과 청년 108명의 정적 화면 의향 조사로 시작·지속의 어려움과 화면 반응을 확인했습니다.
- **내 역할** 조사와 데이터 결과를 받아 또래 비교에서 패턴 확인과 작은 미션으로 이어지는 홈 흐름을 설계했습니다. React 화면과 Spring API를 위한 데이터 규격을 정리하고 목 응답으로 연결했습니다.
- **발표 시점 범위** 목 API로 홈 → 분석 → 미션 흐름을 시연했으며, 실제 마이데이터·실시간 생성형 AI·금융상품 가입은 연동하지 않았습니다. · [최종 발표자료](https://github.com/gaga-studio/finmate-app/blob/main/docs/FinMate-%EB%B0%9C%ED%91%9C%EC%9E%90%EB%A3%8C.pptx) · [회고](https://sjh9714.tistory.com/2)

### [My ETA](https://github.com/tech4good-2026/eta)

> 교통약자의 이동 조건을 반영한 경로와 예상 도착 시간을 안내하는 배리어프리 길찾기

- **내 역할** 백엔드와 외부 교통 API 연결을 맡고, 프론트엔드·AI 파트와 요청·응답 형식과 시연 범위를 조율했습니다.
- **해커톤** 지도·목적지 검색·경로 요청·화면 표시는 실제 API 흐름으로 연결했습니다. 경사·장애물 데이터와 저상버스 API의 정상 응답을 확보하지 못해, 해당 정보와 개인화 ETA는 시연 데이터로 분리했습니다.
- **이후 보완** 프로필 보행속도·경로 구간 거리·GPS 표본을 반영하는 계산 엔진을 API와 화면에 연결했습니다. 실제 교통약자의 이동 시간과 편의성 개선 효과는 아직 확인하지 못했습니다. · [회고](https://sjh9714.tistory.com/1)
